# 🍕 Pizza Sales Analysis - PostgreSQL

Analyzed 21,350 pizza orders (2015 data) to find revenue drivers, peak hours & best sellers.

### 📊 Key Insights
- **Top Revenue:** Thai Chicken Pizza - $43,434
- **Most Sold:** The Classic Deluxe - 2,453 quantity
- **Best Category:** Classic - 26.9% of total revenue
- **Peak Hours:** 12 PM - 1 PM

### 🛠️ Tools
PostgreSQL, pgAdmin4, Excel, Canva
